# 坦克大战 · 幸存者

FC 坦克大战的砖墙、钢墙和俯视炮战，套上吸血鬼幸存者的循环：自动开火、成波敌人、经验拾取、三选一升级，8 分钟一局，最后打掉终焉要塞。

支持 **双人同屏** 和 **Xbox 手柄即插即用**。纯 Canvas 2D + 原生 JS + WebAudio 合成音效，没有任何外部资源，也没有构建步骤。

## 直接开玩

双击 `index.html` 就能玩，也可以起一个静态服务：

```powershell
cd tank-survivors
python -m http.server 8123 --bind 127.0.0.1
# 打开 http://127.0.0.1:8123/
```

浏览器建议 Chrome / Edge / Firefox。手柄走标准 Gamepad API，插上后按任意键即可识别；声音需要先点一下画面或按任意键解锁。

## 操作

| 动作 | P1 键盘 | P2 键盘 | 手柄 |
|---|---|---|---|
| 移动 | `W A S D` | 方向键 | 左摇杆 / 十字键 |
| 瞄准 | 自动瞄准 | 自动瞄准 | 右摇杆（松开回到自动瞄准） |
| 冲刺 | `空格` | `Enter` | `A` |
| 炸弹 | `左 Shift` | `右 Shift` | `X` / `RB` |
| 暂停 | `Esc` / `P` | `Esc` / `P` | `Start` |
| 菜单确认 | `空格` / `Enter` | — | `A` |
| 菜单返回 | `Esc` | — | `B` |

- 单人时方向键也可以控制 P1。
- 双人时第二只手柄自动分给 P2；没有手柄时 P2 用方向键 + `Enter` + `右 Shift`。
- 升级界面：`←` `→` 选择，`空格` / `Enter` / `A` 确认，`1` `2` `3` 直选，也可以直接用鼠标点。
- 手柄原生支持震动（有马达的手柄才会触发）。

## 规则

- **8 分钟一局**。4:00 出现重装坦克，8:00 出现终焉要塞；击毁终焉要塞即胜利。
- **自动开火**：炮塔会锁定射程内最近的敌人。键盘玩家靠自动瞄准，手柄玩家可以用右摇杆手动压枪。
- **升级对全队生效**：任意一名玩家选卡，两名玩家的坦克一起变强。升级选项包括主炮、穿甲、高爆、跳弹、僚机、地雷、电磁链、燃烧弹、护盾、维修、引擎、装甲、弹药架、瞄准镜、磁力、暴击。
- **救援**：队友被击毁后会变成残骸，另一名玩家靠近并停留 2.2 秒即可救回（回复一半生命）。两人同时倒下则本局结束。
- **炸弹**：清掉周围弹幕并造成大范围伤害，初始 3 枚，最多 5 枚。冲刺有无敌帧，冷却 1.45 秒。
- **地形**：砖墙可以打碎，钢墙不行。敌人被墙挡住时会啃砖墙绕路，炮手和 BOSS 的炮弹也会破坏砖墙。
- **拾取**：经验、维修包、炸弹、磁铁。经验满后暂停游戏进入三选一。
- 最高分存在浏览器 `localStorage` 里。

## 目录

```
tank-survivors/
├─ index.html          页面骨架、HUD、标题 / 升级 / 暂停 / 结算界面
├─ styles.css          全部视觉与响应式
└─ src/
   ├─ util.js          数学、RNG、本地存储
   ├─ audio.js         WebAudio 合成音效与循环音乐
   ├─ input.js         键盘 + Gamepad 映射
   ├─ world.js         地图生成、砖墙 / 钢墙、碰撞与出生点
   ├─ game.js          玩家、敌人、武器、升级、波次、BOSS、掉落
   ├─ render.js        Canvas 渲染、相机、坦克绘制、标题吸引场景
   └─ main.js          状态机、菜单、HUD、主循环
```

脚本用经典 `<script>` 顺序加载，共享 `window.TS` 命名空间，所以 `file://` 直接打开也能跑，不需要模块服务器。

## 开发调试参数

URL 参数只用于快速看画面，正常游玩不需要。除 `p` 外都需要配合 `auto=1`（跳过标题直接开局）：

| 参数 | 作用 |
|---|---|
| `?p=2` | 预设双人 |
| `?auto=1` | 跳过标题直接开局 |
| `?t=240` | 开局时间跳到 240 秒（4:00） |
| `?lvl=8` | 按顺序发放前 8 个升级 |
| `?hp=20` | 把玩家生命压到 20，方便看低血量表现 |
| `?boss=1` | 把时间推到 4:00，触发第一个 BOSS |
| `?cards=1` | 开局立刻弹一次升级三选一 |

示例：

```
http://127.0.0.1:8123/?p=2&auto=1&t=235&lvl=10&boss=1
```

## 说明

- 这是独立网页游戏，不依赖 Hearthbox 平台代码；目录也不属于 `hearthbox/` 仓库。
- 没有图片、字体或音频文件，所有视觉和声音都在运行时生成。
- 桌面端体验最佳；手机浏览器可以打开标题页，但本作没有触屏操作，需要键盘或手柄。
