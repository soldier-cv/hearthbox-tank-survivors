# 地图与地形

> 一句话：**地图不是难度阶梯，是战术选择。**
> 每张地图改变的不是"敌人更硬"，而是"你能怎么走、能看见什么、怎么打 BOSS"。

## 1. 为什么不做难度阶梯

如果丛林是简单、水网是困难，那么：

- 水网对 5 台不能渡水的坦克直接变成不可玩
- 玩家会永远待在"最高效刷废铁"的那张图，其余四张白做
- 难度应该由**威胁等级**决定（见 `docs/enemies.md` 第 6 节），地图只提供差异

所以：**地图有"危险度"标注（给新手参考），但不受难度限制，随时可换。**

## 2. 五张地图

| id | 名字 | 危险度 | 核心地形 | 解锁 |
|---|---|---|---|---|
| `proving` | 试验场 | ★☆☆ | 无（基准图） | 免费 |
| `jungle` | 丛林 | ★★☆ | 草丛遮挡视线 | 1200 废铁 |
| `tundra` | 冰原 | ★★☆ | 冰面惯性滑行 | 1200 废铁 |

> 危险度是**给玩家的提示**，不是准入限制。任何地图配任何威胁等级都能玩。

## 3. 试验场（`proving`）

基准图。没有任何特殊地形，只有砖墙和钢柱。**它的存在是给其他四张图当对照组**：玩家在这里学会基础操作，再出去体验变化。

| 项 | 值 |
|---|---|
| 地图尺寸 | 2200 × 1600 |
| 砖墙 | 62 处 |
| 钢柱 | 15 处 |
| 特殊地形 | 无 |

## 4. 丛林（`jungle`）

### 地形元素

| 元素 | 尺寸 | 行为 |
|---|---|---|
| 草丛 | 3–8 格成片 | **遮挡视线**：玩家和敌人在草里都看不见彼此 |
| 枯木 | 1×1 | 可摧毁，掉 8 血 |
| 浅溪 | 2 格宽 | 移速 ×0.75，所有坦克可过 |
| 砖墙 | — | 同基准图，但更少（48 处） |

### 草丛的三条规则

1. **双向遮挡**：草里的敌人你看不见，你看草里的敌人也看不见。**不是单向作弊。**
2. **有破绽**：草里的敌人会摇动草叶（每 0.4s 一次轻微的叶片偏移），**仔细看能发现**。开火的瞬间草里的枪口火焰可见。
3. **可以烧掉**：任何爆炸类攻击（高爆、燃烧、炸弹）会让草丛变成"焦土"，30 秒后消失。**打草惊蛇是有效战术**。

**为什么不是"丛林里敌人隐身而你被偷袭"**：屏幕外被看不见的敌人打死是纯挫败。双向遮挡 + 可摇动 + 可烧掉，三条一起才成立。

### 对 BOSS 的影响

- 铁壁：草丛挡它的射线，也挡你的 → 变成"谁先出草"
- 终焉要塞：环形弹幕在草里看不见 → **明显变难**（这是丛林最危险的地方）

### 视觉

- 草丛：3 层不同深浅的绿色锥形，顶部有 1px 亮边（色板 `#9ad14f` 系）
- 被烧过：深褐 + 少量余烬粒子
- 整体色温偏绿，地面降低亮度以便草丛突出

## 5. 冰原（`tundra`）

### 地形元素

| 元素 | 行为 |
|---|---|
| 冰面 | 无摩擦：松开摇杆后继续滑行，加速度 ×0.45，减速度 ×0.18 |
| 雪地 | 移速 ×0.85，但完全可控 |
| 冰裂缝 | 不可通过（视觉上是深蓝黑），但炮弹可以飞过 |
| 冰块 | 可摧毁，打碎后变成碎冰（滑行表面） |

### 滑行的三条规则

1. **有控制**：仍能转向，只是转向力矩降低。**不是失控**。
2. **有提示**：进入冰面时 HUD 边缘出现一次淡蓝闪光（0.3s），车体拖尾变成白色划痕。
3. **冲刺仍是紧急出口**：冲刺在冰面上照常生效（推力覆盖惯性），这是玩家唯一的"急停"手段。

**为什么不做"滑到停不下来"**：那会让走位变成运气。0.18 的减速度意味着松开后约 1.2 秒停下，玩家能感知并预判。

### 对 BOSS 的影响

- 铁壁：它比玩家重，滑得更厉害 → **它的三连射更容易躲**
- 终焉要塞：你也滑 → **躲环形弹幕变难**

### 视觉

- 冰面：`#c9f5fb` 半透明叠在深蓝上，带 1px 白色反光条纹
- 滑行时：车体后拖出 2 条白色划痕，随速度变长
- 整体色温偏冷，敌方暖色更突出（这张图最好看敌人）

## 6. 水网（`delta`）

### 地形元素

| 元素 | 行为 |
|---|---|
| 深水 | **只有渡水坦克能过**；不能过的坦克被挡在岸边 |
| 浅滩 | 所有坦克可过，移速 ×0.6 |
| 桥 | 可摧毁（HP 120），**打塌后两边都过不去** |
| 河岸 | 砖石，可摧毁，打塌后变成浅滩 |

### 渡水属性

八台坦克里有三台带浮渡改装：

| 坦克 | 渡水 | 代价 |
|---|---|---|
| 回声 ECHO-02 | ✅ | 血量最低（56），防护仅 1 点 |
| 港湾 BASTION-03 | ✅ | 伤害最低（14），移速最慢 |
| 终焉 MK-II | ✅ | 需要通关才解锁 |
| 其余五台 | ❌ | 无 |

**这是刻意的取舍**：渡水是"能走捷径"，不是"更强"。能过水的三台都在别处付了钱——回声脆、港湾慢而软、终焉要通关。

### 敌人的渡水能力

| 敌人 | 渡水 | 战术含义 |
|---|---|---|
| 侦察车、自爆车 | ✅ | 会从水路包抄，不能只守桥 |
| 轻型、炮手、迫击、布雷、护卫 | ❌ | 会绕桥走，桥是咽喉 |
| 重装、狙击、召唤、铁壁 | ❌ | 重装过不了水 → 可以隔河打它 |
| 终焉要塞 | ✅ | 水网对它没有优势 |

**这条设计让水网成为唯一"地形能改变 BOSS 强弱"的地图**：铁壁过不来，终焉要塞随便过。

### 拱桥的战术价值

桥是最好的战场：

- 敌人必须排队过桥 → 高爆一发清一串
- 但桥会被打塌 → 打塌之后自己也没法过
- 河岸可打塌成浅滩 → **"我不需要桥"是一种解法**

### 视觉

- 深水：`#1a4a5c` 基底 + 缓慢移动的横向波纹（2 条，0.5px，周期 4s）
- 浅滩：`#58c8d8` 半透明 + 白色泡沫点
- 桥：木质横板 + 2 条钢梁，受损时木板缺角
- 整体色温偏青蓝

## 7. 废墟（`ruins`）

### 地形元素

| 元素 | 行为 |
|---|---|
| 高墙 | 不可摧毁，但**比钢柱长**（3–6 格），形成真正的通道 |
| 残楼 | 可摧毁（HP 200），倒塌时对周围 90px 造成 40 伤害（**对双方**） |
| 瓦砾 | 移速 ×0.7，可摧毁（HP 60），打碎后变成空地 |
| 弹坑 | 地面凹陷，不影响移动，但会阻挡低矮弹道（视觉提示：深色） |

### 残楼倒塌

这是废墟唯一的机制，也是最危险的：

1. 残楼有 **HP 条**（只有被打到时才显示，3 秒后隐藏）
2. HP 归零 → **0.6 秒预警**（楼体抖动 + 灰尘落下）→ 倒塌
3. 倒塌造成 40 伤害（对玩家和敌人**都算**），并留下瓦砾
4. 倒塌可以**连锁**：砸中另一栋残楼会加速它的倒塌

**为什么对双方都造成伤害**：这样"引敌人到楼下再打塌"是一个真实的战术，而不是单向陷阱。风险与收益对称。

### 对 BOSS 的影响

- 铁壁：高墙能挡它的三连射 → **明显变简单**
- 终焉要塞：高墙挡环形弹幕 → **变简单**（废墟是最容易打 BOSS 的图）

### 视觉

- 高墙：`#43435a` 石质 + 竖向砖缝 + 顶部 2px 亮边
- 残楼：分层色块（3 层），受损时层级逐层消失
- 倒塌预警：楼体左右抖动 2px + 顶部灰尘粒子
- 整体色温偏灰紫

## 9. 地形与威胁等级的组合

**每张图 × 4 个威胁 = 20 种组合，全部可玩。** 但给出推荐搭配（不强制）：

| 地图 | 推荐威胁 | 原因 |
|---|---|---|
| 试验场 | 1–2 | 学习图，别一上来就毁灭 |
| 丛林 | 2–3 | 草丛在有支援兵种时最有意思 |
| 冰原 | 2–4 | 滑行本身够难，敌人可以更狠 |
| 水网 | 2–3 | 渡水 + 包抄是主要压力，不需要再加数值 |
| 废墟 | 3–4 | 高墙给掩体，能承受更高压力 |

## 10. 危险度怎么算

| 地图 | 基础危险 | 加价因素 |
|---|---|---|
| 试验场 | 1 | — |
| 丛林 | 2 | 视野受限（+1） |
| 冰原 | 2 | 操控受限（+1） |
| 水网 | 3 | 通路易断（+1）、包抄（+1） |
| 废墟 | 3 | 环境伤害（+1）、通道压缩（+1） |

**危险度只影响显示与推荐，不影响奖励。** 不做"难度越高废铁越多"——那会逼玩家去最难的图，正好违背第 1 节。

## 11. 每张图必须能回答的问题

做地形之前，先回答这三个问题，答不上就别加：

1. **它改变的是"怎么走"还是"数值"？** 只能是前者。
2. **玩家第一次遇到它时会不会觉得不公平？** 会的话加预警或加破绽。
3. **有没有第二条路？** 水网有桥和浅滩、废墟能打穿瓦砾、丛林能烧草。**任何地形都不能是唯一解法。**

## 12. 实现要点

| 项 | 做法 |
|---|---|
| 地图表 | `config.ts` 的 `MAPS`，每张一条（尺寸、砖墙数、地形元素、生成器 id） |
| 生成器 | `world.ts` 里 `GENERATORS[mapId](rng)`，纯函数，只依赖 `ctx.random` |
| 地形类型 | `TileType` 增加 `GRASS` / `ICE` / `DEEP_WATER` / `SHALLOW` / `BRIDGE` / `RUBBLE` / `BUILDING` |
| 通行判定 | `canPass(tankId, tile)`，坦克的 `amphibious` 属性 + 地形表 |
| 视线 | `hasLineOfSight(x1,y1,x2,y2)`，草丛格阻挡，用于敌人 AI 与狙击手蓄力 |
| 可破坏 | 统一 `damageTile(tx, ty, dmg, source)`，残楼 / 桥 / 河岸 / 草丛各走各的后续逻辑 |
| 随机 | 全部 `ctx.random`，同一 seed 生成同一张图 |
