# 美术规范

> **必须最先定，定完不要改。** 改了所有素材都要重画。
> 本作**零外部素材**：全部由 Canvas 2D 程序化绘制，没有 png、没有字体文件。

## 五项写死

| 项 | 值 |
|---|---|
| 逻辑分辨率 | `960 × 540`（与 `game.json` 的 `display` 一致，`scale: "fit"`） |
| sprite 网格 | 无。所有形状按"半径 + 角度"参数化绘制，不切图 |
| 描边 | 统一 2px 深色描边（`#0b0e10`），车体轮廓另加 1px 亮边（色板第 8 色） |
| 光源方向 | 左上。高光在左上边缘，阴影在右下，偏移 3px |
| 命名规则 | `draw<Tank|Bullet|Terrain|Fx>_<name>`，颜色常量统一 `COLORS.<key>` |

**为什么用 `fit` 而不是 `integer`**：程序化绘制是矢量的，缩放只会更清晰。整数倍会在地图边缘留黑边，电视上很难看。

## 绘制语言

| 元素 | 画法 | 关键尺寸 |
|---|---|---|
| 坦克车体 | 圆角矩形 + 两条履带（深色矩形）+ 炮塔圆 | 车体半径 = 碰撞半径 × 1.05 |
| 炮管 | 从中心沿 `turretAngle` 的矩形，长度 = 半径 × 1.9 | 宽 6px |
| 子弹 | 圆 + 沿速度方向的短拖尾 | 半径 3–5px |
| 砖墙 | 底色 + 2 条横向砖缝 + 随机深浅 | 40 × 40 |
| 钢柱 | 底色 + 内描边 + 4 个角螺栓 | 40 × 40 |
| 爆炸 | 3 层同心圆（`#ff6b35` → `#ffe6b0`），透明度随时间衰减 | 半径随 life |
| 经验球 | 圆 + 内高光点 | 半径 3–5px |
| 火池 | 半透明椭圆，边缘抖动 | 半径 22 |

**不用 `shadowBlur`。** 电视 GPU 上开销大且实测掉帧，用多层半透明圆替代。

## 文字

| 用途 | 字号 | 字体 |
|---|---|---|
| HUD 数值 | 18px | `monospace` |
| HUD 标签 | 11px | `monospace` |
| 卡牌标题 | 20px | `monospace` |
| 卡牌正文 | 12px | `monospace` |
| 大标题 | 54px | `monospace` |
| 结算数字 | 34px | `monospace` |

- **只用 `monospace`**：不加载字体文件（v1 不支持自定义字体）。
- 中文字符在 12px 以下会糊，**正文最小 12px**；11px 只用于极短的标签（"存活""击毁"）。
- 所有文字先 `textAlign = 'center'` 居中绘制，避免长短不一左右歪。

## 视觉层次（电视 3 米外可读）

按"玩家最需要一眼看到"排序，越靠前对比度越高：

1. **玩家自己的坦克** — 亮色主体 + 光晕，永远在画面中心附近
2. **敌人** — 暖红/橙，与背景（冷灰）形成色相差
3. **子弹** — 亮黄白，细
4. **经验球** — 绿，小但高频闪烁
5. **地形** — 最低对比，只做结构提示
6. **HUD** — 边角区域，半透明底衬

## 动效原则

| 效果 | 参数 | 为什么 |
|---|---|---|
| 屏幕震动 | 受击 0.18s / 爆炸 0.12s，幅度 6–14px | 反馈，不制造眩晕；设置里可关 |
| hit-stop | 击杀 BOSS 帧 0.06s | 打击感，不影响操作 |
| 受击闪白 | 0.08s | 最短的可感知时长 |
| 伤害飘字 | 上浮 34px/s，0.75s | 看得清又不糊屏 |
| 敌人死亡 | 粒子 × 8–22，0.4–0.6s | 与体积成正比 |

**动效全部可关**（设置里的 `screen-shake`）。这是平台要求的可访问性底线。

## 允许的格式

**本作不使用任何外部素材。** 如果将来要加：

- 允许：png、jpg、webp、gif、ogg、mp3、wav
- 不允许：svg（运行时解码不一致，且 `assets.image` 返回 `HTMLImageElement` 时不保证尺寸）
- 自定义字体：v1 不支持

## 验收

- [ ] 在 1920×1080 窗口下，画面铺满无黑边、无变形
- [ ] 缩到 960×540，线条依然锐利（矢量绘制，不应当有锯齿）
- [ ] 截图后模糊成缩略图，仍能分辨"自己在哪、敌人在哪"
- [ ] 所有文字在 3 米外可读（把截图缩到 1/3 再看）
- [ ] 关闭屏幕震动后不再有任何画面位移
