# 验收清单

> `typecheck` 通过不算跑通。改到玩家可见的东西，必须真跑起来并截图。

## 每次改动后的最小检查

```bash
cd ../hearthbox
pnpm dev
```

- [ ] 游戏出现在货架上，名字和简介正确
- [ ] 点进去不是黑屏，没有崩溃页
- [ ] 控制台没有红色报错

## 完整验收（发布前）

### 平台契约

- [ ] `dist/game.js` 里没有裸导入（搜 `from '@hearthbox/sdk'` 必须为 0 处）
- [ ] 全文没有 `requestAnimationFrame`、`navigator.getGamepads`、`localStorage`
- [ ] 全文没有 `document.`、`querySelector`、`innerHTML`
- [ ] `Math.random` 为 0 处（全部走 `ctx.random`）
- [ ] `game.json` 的 `id` 与 `defineGame({ id })` 一致

### 能玩

- [ ] 键盘能完成一局（WASD / 方向键 + 空格 + Shift）
- [ ] 手柄能完成一局（如果有手柄）
- [ ] 死亡后能重开，不用刷新页面
- [ ] 有明确的开始和结束
- [ ] 8 分钟能打到终焉要塞，击杀后进入胜利结算

### 敌人

- [ ] 11 种敌人都能实际出现（用威胁 4 + 打满 8 分钟验证）
- [ ] 每种敌人的预警都可见（炮口闪光、狙击红线、迫击收缩圈、自爆闪红）
- [ ] 屏幕外没有狙击手蓄力（只在 620px 且有视线时）
- [ ] 重装坦克正面减伤 60% 生效，绕后就打穿
- [ ] 精英词的 5 种词缀都能出现，视觉可辨
- [ ] 单次受击不超过最大生命 30%（除自爆 / BOSS 蓄力 40%）
- [ ] 压力比值：打满 8 分钟，场上敌人数缓慢上升后稳定，不是瞬间堆满

### 地图与地形

- [ ] 五张地图都能生成，都没有卡死点（出生空地无阻挡）
- [ ] 丛林：草丛双向遮挡；草叶会摇；烧掉后 30 秒消失
- [ ] 冰原：冰面松手后约 1.2 秒停下，仍能转向；冲刺能急停
- [ ] 水网：不能渡水的坦克被挡在岸边；能渡水的能过
- [ ] 水网：侦察车和自爆车会从水路包抄
- [ ] 水网：铁壁 BOSS 过不了水，终焉要塞能过
- [ ] 废墟：残楼被打到 0 血有 0.6 秒预警才倒；倒塌对双方都造成伤害
- [ ] 废墟：连锁倒塌生效
- [ ] 每张图的专属节点各触发一次，且都有预警
- [ ] 水网地图：补给不刷在深水里

### 坦克与兑换

- [ ] 八台坦克都能在机库里选中并出发
- [ ] 每台坦克的属性条与 `docs/tanks.md` 一致
- [ ] 每台坦克的签名技能真的生效（逐台验证，不能只看代码）
- [ ] 渡水属性与 `docs/tanks.md` 一致（回声 / 港湾 / 终焉 能过水）
- [ ] 锁定的坦克显示价格，废铁不足时无法购买
- [ ] 买下坦克后立刻能选，重进游戏仍解锁
- [ ] 五张地图都能购买与选择，地图页签显示"当前坦克渡水：是/否"
- [ ] 四个威胁等级都能选，兵种池按等级变化
- [ ] 废铁在结算页显示，且与存档余额一致
- [ ] 涂装只改颜色，不改任何数值（对比同一台车的两种涂装属性）

### 坦克等级

- [ ] 每台坦克有独立等级，换车不掉级，重进游戏等级保留
- [ ] 八台车同级时，强弱关系与 `docs/tanks.md` 一致（等级不改变排序）
- [ ] 每级属性提升与 `docs/tank-levels.md` 第 3 节公式一致（抽查 Lv1/8/16）
- [ ] 升级费用与公式一致，废铁不足时按钮变灰并显示差额
- [ ] Lv 4 / 8 / 12 各解锁一档外观，且肉眼可辨（截图对比）
- [ ] 八台车的王牌特征（Lv 12）各不相同
- [ ] Lv 6 / 10 / 14 各解锁一阶签名，效果与文档一致（逐台验证）
- [ ] 威胁 2/3/4 分别需要 Lv 5/10/15，未达标时无法选择并显示所需等级
- [ ] 进化预览只在机库里弹，局内不弹
- [ ] 双人各自等级独立，结算废铁按各自贡献算

### 双人分屏

- [ ] 两人贴近 5 分钟，从不分屏
- [ ] 拉开到 1300 px 后 0.22 s 内完成分屏，无黑屏、无视角跳变
- [ ] 靠近到 900 px 后 0.18 s 内合屏
- [ ] 在阈值附近来回走 10 秒，切换不超过 2 次
- [ ] 一人倒地立刻合屏，边缘箭头指向倒地方向
- [ ] 四种地图角落都不露出地图外黑边
- [ ] 设置改成"始终合屏"后，最远距离仍同屏 + 箭头
- [ ] 设置改成"始终分屏"后，单人模式仍是合屏

### 平台能力

- [ ] 金手指面板出现 6 项，拖滑杆立刻生效（移动速度调到 2×，肉眼可见变快）
- [ ] 设置面板出现 5 项，关掉屏幕震动后不再震
- [ ] 成就面板出现 7 项，值与存档一致
- [ ] `god-mode` 打开后不再掉血
- [ ] `inf-bombs` 打开后炸弹数不减
- [ ] 关掉金手指后行为恢复原版

### 特效

- [ ] 关闭屏幕震动后，不再有任何画面位移（包括 `nova` 冲击波）
- [ ] 同屏 160 敌人时，特效不会突破 `docs/fx.md` 的上限
- [ ] 八台坦克的签名特效各不相同（截图并排对比）
- [ ] 没有任何特效闪烁超过 3Hz

### 存档

- [ ] 打出新纪录后立刻退出，重进游戏纪录还在
- [ ] 刷新页面，进度还在
- [ ] 关掉标签页再打开，进度还在
- [ ] 去 `hearthbox` 玩个别的游戏再回来，本游戏存档没被串

### 画面

- [ ] 窗口拉大缩小，画面不变形、不糊
- [ ] 文字在 3 米外能看清（如果目标是电视）
- [ ] 没有元素跑到画面外
- [ ] 升级选卡时三张卡完整可见，焦点框清晰

### 性能

- [ ] 同屏 160 敌人时连续玩 5 分钟不掉帧
- [ ] DevTools Performance 里单帧 < 16ms
- [ ] 没有内存持续增长（Memory 面板连拍三次快照对比）

### 复现

- [ ] `play.html?...&debug=1&seed=42` 两次开局，敌人位置与选卡顺序一致
- [ ] `speed=0.5` 时游戏变慢但不卡顿
