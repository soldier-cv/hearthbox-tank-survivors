# 关卡与节奏

> 单图、单局、8 分钟。没有关卡选择，但**时间轴上有关卡**：每一段都是固定的兵种配方与压力形态。
> 所有时间点写死在这里，代码里只引用常量，不改数值。

## 1. 结构

```
0:00        1:30        3:00        4:30        6:00        7:00        8:00
 |── 集结 ──|── 推进 ──|── 压制 ──|── 割据 ──|──── 终局 ────|
                              ▲ BOSS 1                ▲ BOSS 2（击杀即胜）
```

| 阶段 | 时间 | 压力目标 | 新兵种 | 玩家该学到什么 |
|---|---|---|---|---|
| 一 · 集结 | 0:00–1:30 | 每分钟 1.1 → 2.3 只 | 轻型坦克、侦察车 | 边退边打；砖墙能被自己的炮弹打穿 |
| 二 · 推进 | 1:30–3:00 | 2.3 → 4.0 只 | 炮手（远程） | 别站在开阔地；优先点掉炮手 |
| 三 · 压制 | 3:00–4:30 | 4.0 → 6.2 只 | 自爆车 | 冲刺的时机；用掩体挡爆炸 |
| 四 · 割据 | 4:30–6:00 | 6.2 → 8.4 只 | 精英重装 | 火力不够就会被人海推平 |
| 五 · 终局 | 6:00–8:00 | 8.4 → 10（封顶） | 终焉要塞 | 收尾，把攒的流派打出去 |

**基础刷怪速率**：`1.1 + t × 0.036` 只/秒，上限 12；双人 ×1.18。
**同屏上限**：`165 + 35`（超过后暂停刷怪，避免帧率与可读性一起崩）。

## 2. 波次节点

**节点是"有形状的一波"，不是随机撒怪。** 每个节点按固定阵型投放，让玩家能识别"这是哪一波"。

| 时间 | 节点 | 数量与阵型 | 意图 |
|---|---|---|---|
| 0:00 | 开场包围 | 轻型坦克 ×6，半径 560 环形 | 立刻有事做，不给空场 |
| 0:30 | 装甲纵队 | 轻型坦克 ×10，单侧纵向推进 | 教玩家"用通道卡位" |
| 1:00 | 侧翼夹击 | 侦察车 ×6，左右各 3 | 教玩家别只盯正面 |
| 1:30 | 炮手分队 | 炮手 ×4 + 轻型 ×8 | 第一次被远程打到 |
| 2:00 | 火力压制 | 炮手 ×6，固守砖墙后 | 逼玩家拆掩体进攻 |
| 2:30 | 精英推进 | 精英重装 ×1 + 轻型 ×10 | 第一次遇到"打不动" |
| 3:00 | 混合编队 | 轻型 ×8 + 侦察 ×8 + 炮手 ×4 | 三种威胁同时出现 |
| 3:30 | 自爆冲锋 | 自爆车 ×6，正面直线 | 教玩家用冲刺躲爆炸 |
| 4:00 | **BOSS · 铁壁** | 重装坦克 BOSS ×1（+ 4:20 召唤护卫 ×6） | 第一个阶段检查点 |
| 4:30 | 焦土 | 全类型随机 ×18，精英率 ×2 | BOSS 后立刻加压 |
| 5:00 | 双线突击 | 两侧各 8 只，同时 | 逼玩家分身 |
| 5:30 | 围剿 | 环形包围 ×16 + 自爆车 ×4 | 最密集的一波 |
| 6:00 | 最后抵抗 | 全类型 ×24，精英率 ×3 | 终局前的门槛 |
| 6:30 | 静默 | 刷怪速率 ×0.35，持续 25 秒 | 喘息、捡经验、补炸弹 |
| 7:00 | **BOSS · 终焉要塞** | 终焉要塞 MK-II ×1，常规刷怪停止 | 击杀即胜 |

节点之间的空档由基础刷怪速率填充。**节点不替代基础刷怪，而是叠加**——所以 2:30 那波的精英重装是"额外的"，不是"本该有的"。

## 3. BOSS

### 铁壁（4:00）

| 项 | 值 |
|---|---|
| 血量 | 2800 |
| 半径 | 36 |
| 移动速度 | 38 |
| 行为 | 缓慢逼近；每 2.3s 三连扇形炮击；血量 50% 以下频率 ×1.35 |
| 召唤 | 血量 66% 与 33% 各召唤护卫 ×6 |
| 掉落 | 炸弹 +1、大面积经验球 ×12 |

### 终焉要塞 MK-II（7:00）

| 项 | 值 |
|---|---|
| 血量 | 8200 |
| 半径 | 46 |
| 移动速度 | 30 |
| 阶段一（100%–55%） | 环形弹幕每 3.2s 一圈 16 发；缓慢转向 |
| 阶段二（55%–0%） | 环形弹幕 + 定向扇形 + 召唤自爆车 ×4 每 8s；移速 +25% |
| 击杀 | 立即胜利，结算画面 |
| 掉落 | 无（直接结算） |

**两个 BOSS 都不做无敌帧、不做阶段转场动画。** 玩家要的是"打得更狠"，不是"看得更多"。

## 4. 地形作为关卡

一张 2600 × 2000 的地图（65 × 50 格，每格 40px），每局重生成，但结构固定：

| 元素 | 数量 | 规则 |
|---|---|---|
| 外墙 | 一圈 | 钢，不可摧毁 |
| 砖墙群 | 88 处 | 每格 24 血，可被炮弹打穿，**不会再生** |
| 钢柱 | 15 处 | 不可摧毁，提供硬掩体 |
| 出生空地 | 半径 205 | 永远留空，保证开局不憋屈 |
| 出生外环矮墙 | 12 处（22% 跳过） | 提供第一层掩体 |

**关键设计**：砖墙不重生。一局打到 6 分钟时，战场会从"迷宫"变成"开阔地"——这是主动的节奏变化，也是玩家自己的破坏造成的。所以**越到后期越没有掩体**，压力天然上升，不需要额外加数值。

## 5. 补给节奏

| 时间 | 补给 | 位置 |
|---|---|---|
| 1:30 / 3:00 / 4:30 / 6:00 | 维修箱（回 30 HP）＋ 炸弹 +1 | 地图随机空地，靠近当前玩家 |
| BOSS 死亡 | 炸弹 +1、经验球 ×12 | BOSS 位置 |
| 每次升级 | 三选一卡 | 暂停整个世界 |

补给只在节点时间点刷，不随机掉落——**玩家能预期它**，才不会被迫赌运气。

## 6. 双人规则

| 项 | 值 |
|---|---|
| 同屏 | 是，共享一台电视 |
| 倒下 | 一人血量归零 → 倒地，2.2 秒救援计时开始 |
| 救援 | 队友贴近 48px 内，持续 2.2 秒救起（进度环可见） |
| 全灭 | 两人同时倒地 → 失败 |
| 经验 | 共享等级，两人同时选卡（一张卡对全队生效） |
| 镜头 | 跟随两人中点，两人距离越远镜头越拉远（zoom 1.04 → 0.68） |

## 7. 结算

| 字段 | 来源 |
|---|---|
| 存活时间 | `game.time` |
| 击毁数 | `game.kills` |
| 得分 | `存活秒 × 4 + 等级 × 110 + 击毁 × 12` |
| 新纪录 | 与 `ctx.storage` 里的最佳战绩比较 |
| 用过金手指 | 存档里记 `cheated: true`，结算页标一个小标记 |
