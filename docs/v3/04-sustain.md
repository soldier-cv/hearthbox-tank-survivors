# 生命、恢复与补给

> v1 有"维修组"（每秒回 0.85），v2 把它改成了定时包，v3 要把**恢复重新做成一门正经机制**：
> 回血是资源，也是决策；不能白给，也不能没有。

## 1. 生命模型

| 项 | 值 | 备注 |
|---|---|---|
| 基础生命 | 88 | 铁砧 |
| 单次受击上限 | 30% 最大生命 | 满血不会被一击秒 |
| 受伤后无敌 | 0.6s | 防止贴脸连续掉血 |
| 护甲 | 5%（底盘） + 卡 | 上限 15% |

## 2. 三条恢复渠道（互相独立，各管一件事）

| 渠道 | 数值 | 触发 | 定位 |
|---|---|---|---|
| **维修组（卡）** | 0.8/s 每级，最高 3 级 | **脱战 2 秒后** | 长期续航：鼓励拉开距离 |
| **击杀掉落（系统）** | 小血包 +6，3% 概率；精英 +15，20% | 击杀瞬间 | 战斗奖励：打得凶就回得多 |
| **定时补给（系统）** | 维修箱 +30，炸弹 +1 | 1:30 / 3:00 / 4:30 / 6:00 | 可预期的节点：让玩家敢去冒险 |

**三条都必须存在。** 只有卡回血，没拿卡的人必死；只有掉落，运气决定生死；
只有定时补给，节奏太死。

### 2.1 为什么维修组要"脱战才回"

- 边打边回 = 站着对射，和"移动躲弹"的核心循环相反。
- 脱战 2 秒是一个可感知的门槛：你知道"再撑两秒就开始回"。
- 质变 A「战地」把这条门槛拆掉（0.4/s），这是**用一张质变换打法**，而不是白送。

## 3. 护盾

| 项 | 值 |
|---|---|
| 基础 | 1 层，吸收一次伤害，9.5s 自充 |
| 叠层 | 最多 3 层（力场护盾 3 级） |
| 破碎反馈 | 六边形碎裂 + 一圈光，音效独立 |
| 质变 | A 破碎冲击波（320px / 80 伤害）；B 反伤弹片（12 发） |

护盾的定位是"容错"，不参与回血计算。

## 4. 拾取与补给

| 类型 | 外观 | 效果 | 掉落 |
|---|---|---|---|
| 经验球 | 绿色小球 | +经验 | 击杀必掉 |
| 小血包 | 绿色十字 | +6 生命 | 击杀 3% |
| 精英血包 | 绿色大十字 | +15 生命 | 精英 20% |
| 维修箱 | 绿色方块 + 十字 | +30 生命 | 定时补给 |
| 炸弹 | 黄色圆点 | +1 炸弹 | 定时补给 / BOSS |

规则：
- 拾取范围 92，磁力回收卡加到 ~230。
- **投放时必须三件套**：Toast 一行字 + 落地脉冲环 + HUD 倒计时（v2 缺了这个，玩家根本没发现补给）。
- 补给刷在离玩家 120–200px 的空地，不刷在深水。

## 5. 炸弹

| 项 | 值 |
|---|---|
| 初始 | 3 颗，上限 5 |
| 效果 | 半径 320，伤害 150 + 等级 ×6，清屏敌弹 |
| 定位 | 解围，不是输出 |

炸弹是"我快要死了"的按钮，所以不做自动补充，只从补给和 BOSS 拿。

## 6. 经济（局外）

| 来源 | 数值 |
|---|---|
| 击杀 | 0.4 废铁/只 |
| 存活 | 0.5 废铁/秒 |
| BOSS | 120 |
| 通关 | 400（首通 800） |
| 失败 | 按 60% 结算 |

废铁只做一件事：**解锁新坦克/地图/涂装**，不买数值。

## 7. 失败与撤离

| 情况 | 结果 |
|---|---|
| 打死最终 BOSS | 胜利，全额废铁 |
| 8 分钟到但没打死 | 撤离，60% 废铁（这局算完成） |
| 阵亡 | 失败，60% 废铁，重来 |

**"撤离"必须是一种成功**：回收员的设定下，活着带走东西就叫成功。这样玩家不会因为"没打死 BOSS"而觉得白玩。

## 8. 验收

- [ ] 不拿任何恢复卡，靠掉落 + 补给能活到 6 分钟（说明渠道 ≥ 2 条在起作用）
- [ ] 拿满维修组 + 脱战，能在 20 秒内从 30% 回到 80%
- [ ] 补给投放后 3 秒内，玩家能找到它（找人试玩，问"刚才掉了什么、在哪"）
