# 关卡与开发计划

> 先把**一台车、一张图、一条时间轴**做到手感对，再谈内容和战役。

## 1. 一局的形状（沿用 v1，不改 8 分钟）

```
0:00        1:30        3:00        4:30        6:00        7:00     8:00
 |── 集结 ──|── 推进 ──|── 压制 ──|── 割据 ──|──── 终局 ────|
                              ▲ BOSS 1                ▲ BOSS 2
```

| 阶段 | 时间 | 玩家在学什么 | 第一次出现的东西 |
|---|---|---|---|
| 集结 | 0:00–1:30 | 边走边打 | 轻型、侦察 |
| 推进 | 1:30–3:00 | 别站在开阔地 | 炮手、第一次定时补给 |
| 压制 | 3:00–4:30 | 冲刺时机 | 自爆车、第一张满级质变 |
| 割据 | 4:30–6:00 | 绕位 | 重装、精英 |
| 终局 | 6:00–8:00 | 把构筑打出去 | BOSS 2 |

**每个阶段的"第一次"都要被设计过**：第一次补给、第一次质变、第一次精英、第一次 BOSS，
不能靠随机撞上。

## 2. M1：只有一台坦克

### 2.1 内容范围

| 项 | M1 做什么 | 不做 |
|---|---|---|
| 坦克 | **1 台（铁砧）** | 其余 7 台（数据保留，机库里锁住） |
| 地图 | 1 张（试验场） | 丛林/冰原/水网/废墟 |
| 敌人 | 6 种：轻型、侦察、炮手、自爆、重装、铁壁 BOSS | 其余 5 种 |
| 卡 | 23 张（`03-cards.md`） | 元素组合（M2） |
| 关卡 | 8 分钟 + 1 个 BOSS（4:00 铁壁） | 终焉要塞、战役线 |
| 双人 | 不做 | M3 |
| 机库 | 保留（只显示一台车、一张图） | 涂装/等级/解锁（M2） |

### 2.2 M1 的验收（手感关）

| 项 | 标准 |
|---|---|
| 震屏 | 采样 10 秒，震屏帧 < 3% |
| 炮塔 | 10 秒内反向 < 2 次 |
| 数字 | 同目标 0.2s 合并，最多 40 条 |
| 清场 | 10 个普通敌人 4–6 秒 |
| 质变 | 每局至少触发 1 次，且有专属演出 |
| 回血 | 三条渠道都能被玩家说出来 |
| 卡面 | 只看 3 秒能说出"这张改什么" |

## 3. M2：第二台坦克 + 元素组合

| 项 | 内容 |
|---|---|
| 坦克 | +1 台（回声 / 轻快，签名：冲刺） |
| 元素组合 | 火+电爆燃、冰+酸脆化（先做两条） |
| 地图 | +1 张（丛林，草丛能被烧） |
| 卡 | +4 张（元素专精红卡、第二台车专属） |
| 机库 | 坦克等级、涂装、解锁接回来 |

**M2 的唯一目标**：证明"同一套卡，两台车打出来不一样"。

## 4. M3：战役与更多内容

战役线沿用 `docs/campaign.md` 的八个节点（代号 + 战史 + 每关一个独有机制），
但每关的规则必须由 M1/M2 里已经验证过的系统组合而成，不新增系统。

## 5. 排期（按人天，含自测）

| 阶段 | 内容 | 估时 |
|---|---|---|
| M1-a | 战斗反馈（停帧/白闪/震屏限流/数字合并/音效分层） | 2 天 |
| M1-b | 卡池重构（23 张 + 3 级 + 满级质变 + 候选规则） | 3 天 |
| M1-c | 恢复与补给（三条渠道 + 投放提示 + HUD） | 1.5 天 |
| M1-d | 内容收敛（1 车 1 图 6 敌）+ 机库锁定 | 1 天 |
| M1-e | 手感验收（按第 2.2 节逐项测） | 1.5 天 |
| **合计** | | **9 天** |

M1 完成前不开 M2。

## 6. 开发顺序（为什么这样排）

1. **先做反馈**：因为卡池再多，打起来不爽也没用。而且反馈改动小、可立刻用 v1 的场景验证。
2. **再做卡池**：反馈稳了之后，才知道"质变"要多大的演出预算。
3. **最后做恢复/内容收敛**：这两块是"把别的都串起来"，放最后不会返工。

## 7. 需要拍板的三个问题

1. **代码基线**：继续用 v1 的平台版（地图/敌人/存档/相机都在），还是把 `legacy/` 的独立 demo 整体搬进平台？
   —— 我建议前者：引擎不是问题，卡池和手感才是。
2. **卡等级**：3 级封顶（本文），还是像 legacy 那样 4–6 级？
   —— 3 级能保证一局摸到 2–3 张满级，6 级会让一局只够练一条线。
3. **失败结算**：维持"失败也给 60% 废铁"，还是改成"必须撤离才算完成"？
   —— 前者对新手友好。
