## 为什么推倒重来

v2 做对了一件事：**先拿到卡、之后才改装它**。但它同时删掉了 v1 最重要的东西——
一张卡从"有"到"变强"的**高光时刻**（5 张终极卡各有一套专属演出）。
结果是：结构对了，手感垮了。抖动、炮塔来回甩、卡面像填表，都是"只盯着结构、
没盯着每一秒的反馈"的结果。

v3 的原则反过来：**先定"每一秒是什么感觉"，再定卡池。**

## 三层结构（全篇的基础）

| 层 | 是什么 | 谁改它 | 例子 |
|---|---|---|---|
| **主炮** | 永远存在的一门炮，负责"发子弹" | 主炮卡 | 伤害、射速、并联、射程 |
| **弹药** | 这一发子弹的**性质** | 弹药卡 | 穿甲、高爆、跳弹、燃烧、电弧、冰霜、酸蚀 |
| **装置** | 不靠主炮的独立东西 | 装置卡 | 僚机、布雷、电塔、炮台、护盾 |
| **底盘** | 车本身 | 底盘卡 | 血、甲、速、拾取、维修 |

**弹药和装置必须分开。** 弹药改变"你打出去的那一发"，装置是"另一件在做事的東西"。
玩家要能一眼看出"这张卡改的是我的子弹，还是给我加了个帮手"。

## 支柱

| 支柱 | 一句话 | 反面（v2 犯过的） |
|---|---|---|
| **一颗子弹** | 所有输出都从主炮的子弹出去 | 29 个小系统同时在场，看不清谁在打 |
| **元素是状态** | 火/电/冰/酸都会留在敌人身上，看得见 | 元素只是换个颜色和数字 |
| **质变有演出** | 每一张卡满级都有一次专属表现 | 升级只是数字变大 |
| **反馈优先** | 命中、暴击、击杀必须有反馈，且**不能刷屏** | 每次爆炸都震屏 → 一直在抖 |
| **先拿后用再改** | 卡片先到手，用两轮之后才出现它的改装 | 刚拿到就能改，等于没用过 |

## 参考（学什么、不学什么）

| 游戏 | 学 | 不学 |
|---|---|---|
| 《向末日开炮》 | 单武器 + 部件强化 + 元素，节奏快 | 过多的养成线 |
| Vampire Survivors | 武器/被动分离，升级到 5 级质变 | 满屏数字与特效堆叠 |

| 20 Minutes Till Dawn | 火+电=爆炸这类元素组合 | 太依赖走位躲弹幕 |
| Nova Drift | **子弹改造**的极致：弹道/元素/分裂 | 操作复杂度 |

## 成功标准（可测，不是感觉）

一局 8 分钟跑完，满足以下全部才算"手感对了"：

| 指标 | 目标 | 怎么测 |
|---|---|---|
| 震屏帧占比 | < 3% | 采样 `fx.shakeAmp > 0` 的帧 |
| 炮塔反向次数 | < 2 次/10 秒 | 记录 `turretAngle` 方向翻转 |
| 10 个普通敌人的清场时间 | 4–6 秒 | 固定出生 10 只，计时 |
| 一局"高光"次数 | ≥ 3 | 元素质变 / 红卡 / 连锁爆炸各算一次 |
| 升级决策时间 | < 3 秒 | 从弹出到确认的中位数 |
| 玩家能否说出构筑 | 30 秒内能说出"我这局在堆火" | 自测或找人试玩 |
