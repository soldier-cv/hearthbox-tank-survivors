# 元素系统：火 / 电 / 冰 / 酸

> 一条原则：**元素不是换个颜色，是给敌人挂一个看得见的状态。**
> 每个状态都要有一个"中间态"——火在身上烧、电在敌人之间跳、冰在脚下、酸在冒烟。

## 1. 四种元素

| 元素 | 色 | 附着（绿卡） | 质变（蓝卡） | 强在 | 弱在 |
|---|---|---|---|---|---|
| **燃烧** | `#ff6b35` | 命中点燃 3s（8/s） | 火池蔓延、着火的敌人拖火痕 | 人海、草丛 | 单体、BOSS |
| **电弧** | `#7bd6ff` | 命中电击最近 1 个（60px） | 连锁 +2，被电目标受伤 +15% | 密集、护盾 | 单点 |
| **冰霜** | `#c9f5fb` | 减速 30% | 减速满 2s 后定身 1s，定身受伤 +25% | 保命、集火 | 不直接加伤害 |
| **酸蚀** | `#b6e04a` | 破甲：受到伤害 +10%（叠 3 层） | 被酸蚀目标死亡时向周围溅射 | 精英、BOSS | 小兵打得慢 |

**每一种元素都必须能单独成立**（不靠组合也能打），组合只是"更爽"，不是"唯一解"。

## 2. 状态规则

```
命中 → 附着（0.2s 内可见的一次闪光）
     → 持续 3s（状态图标 + 身上效果）
     → 质变卡满足条件 → 进阶效果
```

| 规则 | 内容 |
|---|---|
| 同时只能有一种元素 | 新元素覆盖旧的（避免叠加到不可读） |
| 状态时长 | 统一 3s，冰霜的定身 1s 单独计时 |
| 对 BOSS | 状态生效但时长 ×0.5，定身改为减速 |
| 视觉 | 火：3 个跳动的火苗；电：随机 1–2 条电弧跳到附近单位；冰：脚下六角环；酸：绿色气泡 |
| 音效 | 每种元素一个持续底噪，**同一时间只播最响的那一种** |

## 3. 组合（M2 才做，M1 预留数据位）

| 组合 | 触发 | 效果 | 演出 |
|---|---|---|---|
| **火 + 电 = 爆燃** | 着火目标被电击 | 半径 70 爆炸（伤害 = 火 3s 总量） | 橙白冲击环 + 火星四散 |
| **冰 + 酸 = 脆化** | 定身目标被酸蚀 | 受到伤害 +40%，定身时间 +0.5s | 冰面裂纹 + 绿色渗入 |
| **火 + 冰 = 蒸汽** | 着火目标被冰减速 | 生成 2s 蒸汽区：区域内敌人命中率下降（子弹偏移） | 白雾，边缘慢速扩散 |
| **电 + 酸 = 腐蚀云** | 酸蚀目标被电击 | 周围 90px 留下 3s 腐蚀云（6/s） | 绿蓝色雾 + 电弧闪光 |

**组合的触发条件必须写在卡面上**（"点燃的目标被电击时爆炸"），
但**不告诉玩家具体数值**——让玩家自己去试。

## 4. 元素与卡池的关系

每元素两张卡（附着 + 质变），四个元素 = 8 张。第 9 张元素类卡位留给
**"元素专精"**（红卡，M2）：把你当前唯一的元素伤害 ×1.6，但没有第二元素。

## 5. 为什么不做"元素伤害类型/抗性表"

那会让玩家在选卡时查表算数。这里只有一种伤害，元素只加**状态**。
敌人可以"怕"某种状态（比如机械单位被电击时连锁 +1），但不做百分比抗性。

## 6. 视觉预算

| 状态 | 同时最多 | 说明 |
|---|---|---|
| 火苗 | 40 个敌人 | 超出后只保留离玩家最近的 40 个 |
| 电弧 | 12 条 | 超出丢弃最旧 |
| 冰环 | 40 个 | 与火苗共享预算 |
| 酸雾 | 10 团 | 每团 3 个粒子 |

元素效果**宁可少画，也不要糊成一片**。判断标准：截图缩小到 50% 还能看出是什么元素。
