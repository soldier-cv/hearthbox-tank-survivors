# 玩法一页纸

> 填完这一页才能开始写代码。填不出来的行，说明还没想清楚。

## 一句话

玩家驾驶一辆坦克，在被炮火一点点打烂的封闭试验场里收割成波涌来的装甲部队，靠升级把弹幕堆成一道墙。

## 核心动词

**射击**

只能有一个。去掉它，剩下的移动、破墙、救援全部失去意义。

## 八个字段

| 项 | 内容 |
|---|---|
| 核心动词 | 射击 |
| 玩家在做什么 | 边走位边持续开火；子弹会打碎砖墙，战场随每一局被自己重塑 |
| 失败条件 | 单人：生命归零。双人：两人同时倒下（一人倒下可被队友靠近救起） |
| 成功条件 | 击杀终焉要塞 · MK-II |
| 一局时长 | 8 分钟（7:00 进入终局，8:00 停止常规刷怪，击杀要塞结束） |
| 需要的按键数 | 方向键之外 4 个：冲刺、炸弹、暂停、手动瞄准（可关） |
| 是否需要鼠标 | 否 |
| 一句话卖点 | 你的炮弹会拆掉战场本身——掩体既是你的墙，也是你的弹药消耗品 |

## 第一分钟

1. 进场，屏幕中央是 400px 见方的空地，四周是稀疏砖墙与钢柱。HUD 只有存活时间、等级、经验条、击毁数。
2. 0:05 第一波轻型坦克从视野外开进来，慢、直、可被撞开。玩家自然学会"边退边打"。
3. 0:25 打碎第一面砖墙，墙后露出通道——玩家第一次意识到地图是可破坏的。
4. 0:40 升到 2 级，屏幕停下，三张卡出现。选"主炮强化"，射速与伤害肉眼可见地变快。
5. 0:55 侦察车从侧翼斜插进来，速度快到必须用冲刺拉开距离。

## 操作检查

- [x] 只需要 `ctx.input.p1`（手柄层）就能玩
- [x] 不需要鼠标（`pointer: "hidden"`）
- [x] 一个从没玩过的人看截图能猜出要做什么：坦克、弹幕、成群的敌人、顶部的存活计时

## 操作映射

| 动作 | 手柄 | 键盘 |
|---|---|---|
| 移动 | 左摇杆 / D-pad | WASD / 方向键 |
| 瞄准 | 右摇杆（松开后自动瞄准最近目标） | 自动瞄准 |
| 冲刺 | south (A) | 空格 |
| 炸弹 | west (X) / r1 | 左 Shift |
| 暂停 | start | Esc / P |
| 选卡 | 十字键左右 + south | ← → + 空格 / 1 2 3 |

> 平台把空格默认映射到 `south`，所以"冲刺"和"确认"在同一颗键上——这是有意的：非菜单状态下 `south` 就是冲刺，菜单状态下才是确认，由状态机分流，不会双触发。

## 不做什么

明确列出这一版**不做**的：

- 不做联机、不做排行榜（平台 v1 是单机）
- 不做装备栏 / 改造件 / 词条随机（技能只有 5 流派 × 4 级 + 终极）
- 不做关卡选择（单图单局，进度靠成就与最佳战绩体现）
- 不做自定义键位（`keybinding` kind 平台尚未实现）
- 不做无尽模式（8 分钟封顶，避免数值曲线失控）
- 不做像素贴图（纯 Canvas 程序化绘制，零外部素材）
- 不做存档中途续玩（一局最长 9 分钟，成本不值）
