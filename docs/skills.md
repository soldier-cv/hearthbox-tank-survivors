# 技能体系

> 5 个流派 × 4 级 + 每条流派的终极质变。**这是构筑的方向感来源**：玩家在第 2 分钟就该知道自己在往哪个方向堆。
> 所有技能只做"速率与形态"，不改进度结构（见 `docs/../hearthbox/docs/tuning.md` 硬规则 3）。

## 1. 规则

| 项 | 规则 |
|---|---|
| 升级节奏 | 每次升级出 3 张卡；同一流派内的卡只在该流派未满级时进入候选池 |
| 单卡上限 | 4 级（Ⅰ → Ⅱ → Ⅲ → Ⅳ） |
| 终极 | 某流派 4 级集齐后，**下一次升级**该流派的终极卡必定出现（且只出一次） |
| 卡池权重 | 基础权重 1.0；已选过 1 级的流派权重 ×1.35（引导走深而非撒网） |
| 排除规则 | 已满级的卡、已获得的终极卡，不再进入候选池 |
| 重选 | 每局 2 次重选（`reroll`），按键 `west` / `KeyQ` |

**为什么是"每流派 4 级 + 终极"而不是无限叠**：4 级之后那张卡就消失了，玩家不会在后期抽到"再升一次主炮"这种无效选项，每次升级都必须有意义。

## 3. 卡池与抽取

```
候选池 = 全部未满级卡 + (已集齐流派的终极卡，仅一次) − 已拿的终极卡
权重   = 基础 1.0 × (该流派已投入等级 > 0 ? 1.35 : 1.0)
```

**三选一必须互不重复**，且至少 2 张来自不同流派（避免"三张都是火力但都满了"的尴尬）。

**保底**：如果候选池只剩 1 张，直接给那张；剩 0 张（极端情况，全满级）给"补给卡"——回 30 血 + 1 炸弹 + 少量分数。

## 4. 与平台可调项的对应

流派等级是**游戏内进度**，不进平台面板。平台面板只放"玩家在游戏外就能决定"的东西：

| 面板 | 项 |
|---|---|
| 金手指 `cheat` | 移动速度、射速倍率、经验倍率、出怪速度、无敌、无限炸弹 |
| 设置 `setting` | 屏幕震动、伤害数字、自动瞄准、瞄准辅助强度、界面缩放提示 |
| 成就 `status` | 最高存活、最高击毁、到达过的最高等级、击杀 BOSS 次数、通关次数 |

**这是有意的分工**：技能树是玩法，可调项是"我想怎么玩这个游戏"。把技能等级做成可调项等于让玩家买通关。

## 5. 数值来源

以上所有数字进 `src/config.ts` 的 `UPGRADES` 表与 `src/tuning.ts` 的 `baseline`。**代码里不出现裸数值**：`calcStats()` 只读表，不写 `+5`、`×1.09`。
