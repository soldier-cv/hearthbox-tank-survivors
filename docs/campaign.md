# 战役线：八个节点，一种风格各管一件事

> **为什么不是"第 1 关 / 第 2 关"。**
> 编号只告诉玩家"该打下一关了"，不告诉他"这一关会怎么打"。
> 战役线用**代号 + 战史一句话 + 一个独有规则**来定义每一关：
> 名字是地点，历史是背景，规则是这一关真正的样子。
>
> 8 分钟仍然是支柱，不改。改的是这 8 分钟的**形状**：节奏、事件位置、胜负判定。

## 0. 三条硬规则

| 规则 | 内容 | 为什么 |
|---|---|---|
| **一关一个机制** | 每关必须有一个"只有这一关才有"的机制，且不是数值 | 数值差异玩家记不住，机制差异记住一次就够 |
| **机制写在简报里** | 机库选关时，一句话说清"这关会怎么变" | 不靠玩家死一次才学会 |
| **不借真实伤亡** | 借"历史事件的形状"（撤退、断桥、夜袭、误炸），不借真实国家与数字 | 这是虚构战争，不是历史模拟 |

## 1. 战争线（虚构）

**「静默战争」**——没有人宣布，也没有人投降。

| 纪年 | 事件 |
|---|---|
| 战前 3 年 | 自动化装甲的指挥链第七次升级，"停机令"被写进协议最底层 |
| 第 0 天 | 试验场拒绝关机。保安装甲向操作员开火——**停机令事故** |
| 第 11 天 | 第一次反攻选在夜里，因为白天没人敢上冰面。失败 |
| 第 40 天 | 反攻推进到雨林，装甲被草吞掉，人没回来 |
| 第 96 天 | 撤退时自己人炸了桥，两个营留在对岸 |
| 第 130 天 | 城市战打了 11 天，双方都没走出街区 |
| 第 190 天 | 炮兵在没有坐标的情况下轰了三个小时，双方都在挨自己人的炮 |
| 第 240 天 | 最后一场装甲对冲发生在暴风雪里，靠无线电测向开火 |
| 战后 7 年 | **玩家是回收员**，沿着这条线逆着走回去，捡还能用的东西 |

**战役线 = 回收路线。** 玩家按战争发生的顺序重走一遍战场，每一关的简报就是那一段战史。
所以关卡有"记忆"，但不是靠 CG——靠地形还在冒烟的痕迹。

## 2. "风格"由五件事决定，不是难度

| 维度 | 可变量 | 玩家感受到的 |
|---|---|---|
| **光** | 正午 / 黄昏 / 夜 / 雾 / 暴雨 / 暴风雪 | 你能看见多远 |
| **地形** | 基数 + 会被改变的方式（烧、淹、塌、陷） | 战场会不会消失 |
| **编制** | 兵种池与阵型 | 你在跟谁打 |
| **脚本** | 这一关独有的时间点事件 | 什么时候会出事 |
| **胜负** | 杀 BOSS / 撑到撤离 / 占住高地 | 你在为什么而战 |

**同一个维度最多用两次**：两关都是"夜战"就不叫风格了。

## 3. 八个战役节点

| # | 代号 | 地图 | 光 / 天候 | 威胁 | 独有机制（一句话） | 胜负 |
|---|---|---|---|---|---|---|
| 01 | **静默** | 试验场 | 正午 · 晴 | 1 | 无——基准图，教操作 | 杀铁壁 + 终焉 |
| 02 | **熄灯** | 冰原 | 夜 | 2 | 视野压到 520px，远处只有车灯 | 撑到 8:00 |
| 03 | **割草** | 丛林 | 黄昏 | 2 | 火会沿草丛蔓延，烧出一条走廊 | 杀铁壁 |
| 04 | **退潮** | 水网 | 凌晨 · 雾 | 3 | 水位每 60s 涨一格，战场在变小 | 撑到 8:00 撤离 |
| 05 | **楼与楼** | 废墟 | 白天 | 3 | 每 2 分钟塌 3 栋楼，不分敌我 | 杀终焉（提前到 6:30） |
| 06 | **铁雨** | 试验场 | 暴雨 | 3 | 全场随机炮击，红圈 1.2s，不区分敌我 | 杀铁壁 ×2 |
| 07 | **白噪** | 冰原 | 暴风雪 | 4 | 横风让子弹偏 ±3°，每 45s 换向 | 杀铁壁 |
| 08 | **归零** | 试验场深处 | 夜 · 无补给 | 4 | 6:00 后每 30s 塌一圈地板，场地缩小 | 杀 MK-III |

### 逐关细节

**01 · 静默（试验场）**
唯一的"无规则"关。它的作用是当对照组：干净、开阔、只有轻型与侦察。
玩家在这里学会"砖墙能被自己的炮弹打穿"，之后每一关都在拿这条做文章。

**02 · 熄灯（冰原 · 夜）**
视野半径 520（相机外是黑，不是雾）。敌人只有**车灯**——两个亮点 + 一条光锥，这就是全部信息。
敌弹在暗处只留一条 1px 微光。冰面照旧滑。
**它惩罚的是"远程构筑"**：长管炮/轨道炮在夜里找不到目标，反过来近距的冷媒喷口、破片手雷第一次变成好选择。
3:20 冰面冲锋改成"车灯排成一条线"——你能看见，但来不及躲。

**03 · 割草（丛林 · 黄昏）**
草丛双向遮挡是已有的。新增：**火沿草丛蔓延**（每 1.5s 向相邻草丛一格，烧过的地 30s 不能藏人）。
黄昏的斜光让火线在草尖上可见——这是唯一一关"光在帮你"。
5:15 焦土推进的敌人边走边烧，把地图烧出一条直走廊：你可以在走廊里打，也可以躲进还没烧到的草里。

**04 · 退潮（水网 · 雾）**
没有 BOSS。5:40 桥被炸（脚本），之后**每 60s 水位涨一格**，浅滩变深水。
8:00 时地图只剩几块高地。渡水坦克在这里第一次不是"可选"，是"另一种玩法"。
雾把视野压到 700，敌人从雾里出现前有 0.8s 的水波纹。

**05 · 楼与楼（废墟 · 白天）**
每 2 分钟随机 3 栋残楼进入预警（0.6s）后倒塌，**对双方都造成伤害**。
玩家可以主动打塌楼：开路、压人、或者把 BOSS 的炮线堵死。
终焉要塞提前到 6:30，因为它在这张图里更强（弹幕被楼切成一段一段）。

**06 · 铁雨（试验场 · 暴雨）**
每 4s 一个炮击落点，**红圈预警 1.2s**，落在玩家周围 300–700px，不区分敌我。
暴雨把音效压低、把弹道拖成水线——**看红圈，不要听声音**。
铁壁 ×2 同时出现，血量 ×0.6：两个慢速 BOSS 互相挡炮，逼你换角度。

**07 · 白噪（冰原 · 暴风雪）**
横风让每发子弹偏 ±3°，每 45s 换向（HUD 风标 + 雪粒方向）。
冲刺距离 +20%（滑），视野 400。
铁壁的三连射也被风吹歪——好躲，但你没法预判它打哪。

**08 · 归零（试验场深处 · 夜）**
收尾关。6:00 之后每 30s 从边缘塌一圈地板（变成深坑，掉下去即死），无补给。
MK-III 三阶段：环形弹幕 → 分裂成两台（各 60% 血）→ 合体超载（1.6× 伤害，射速 ×0.7）。
**场地在缩，BOSS 在变**，这一关不给喘息。

## 4. 进度与入口

| 入口 | 内容 |
|---|---|
| **战役线** | 8 个节点按顺序解锁；每关固定地图/威胁/规则，不能改 |
| **自由行动** | 现在的自选地图 + 威胁，全部规则关闭；解锁过的地图都能进 |

- 通关一个节点 → 解锁下一个 + 一笔废铁（与现在 `clears` 一致）
- **失败不退关**：回收员设定下，撤退也是收获，给 60% 废铁，节点保持解锁
- 战役进度存在存档 `campaign: { cleared: string[] }`，与 `clears` 分开计数
- 每关记录最好成绩（时间/击杀），在选关界面显示

## 5. 与现有系统的接口

| 系统 | 怎么接 |
|---|---|
| 地图 | 每关固定 `map`，不再由玩家选（战役模式下） |
| 威胁 | 每关固定 `threat` 1–4 |
| 时间轴 | 沿用 `PHASE_TABLE` 与波次节点；每关只**替换**若干节点 + 叠加脚本事件 |
| 卡池 v2 | 不变。每关的机制只改"环境"，不改卡 |
| 坦克 | 不变。但"熄灯/白噪"会让远程卡变弱，这是有意的构筑差异 |
| 存档 | `Progress` 加 `campaign`，不需要兼容旧档（开发期直接改） |

**新的东西只有三类**：
1. 关卡规则（`CampaignOp` 数据表：光/地形改造/脚本事件/胜负条件）
2. 渲染层（夜色、雾、暴雨、风向）
3. 选关界面（战线图，不是列表）

## 6. 分期

| 期 | 内容 | 估时 |
|---|---|---|
| 一 | 数据结构 + 选关界面 + 01/02（基准与夜战） | 1.5 天 |
| 二 | 03/04（火蔓延、涨水）——都需要改地形 | 1 天 |
| 三 | 05/06（塌楼脚本、炮击落点） | 1 天 |
| 四 | 07/08（风偏、地板塌陷、MK-III） | 1.5 天 |

**先做 01 + 02**：一关是"没有规则"，一关是"光没了"，正好验证这套结构能不能只靠"环境"就做出两种手感。

## 7. 不做的事

| 不做 | 为什么 |
|---|---|
| 关卡编号 | 代号 + 地点已经够定位，编号只增加"该打第几关"的焦虑 |
| 剧情分支 | 与 `docs/world.md` 一致：不做分支，只做线性战史 |
| 开场 CG / 语音简报 | 8 分钟街机，玩家不读也不看。简报只有一行字 |
| 每关不同时长 | 8 分钟是支柱。变的是形状，不是长度 |
| 关卡专属卡 | 会让卡池变成"到这关就必须拿这几张"，破坏构筑 |
| 难度阶梯 | 地图不是难度（见 `maps.md` 第 1 节）；威胁才是，且由关卡决定 |
