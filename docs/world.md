# 世界观与角色

> 可以边做边长。这里只定"必须一致"的部分：谁在打谁、为什么、舞台是什么。

## 设定

一座废弃的**装甲试验场**。战前是武器测试基地，现在被失控的自动化装甲部队占据。

玩家不是军人，是**回收员**——开着唯一还能动的试验车，进去把还能用的东西拖出来。所以：

- 弹药有限 → 所以有"炸弹"这种稀缺资源
- 场地会塌 → 所以砖墙可以被自己的炮弹打穿
- 敌人是旧型号 → 所以它们有型号名，不是怪物

## 角色

### P1 · 「铁砧」（ANVIL-01）

| 项 | 内容 |
|---|---|
| 车体 | 试验场一号原型车，琥珀涂装 |
| 性格 | 沉默、耐揍、把话省到最后一句话 |
| 台词基调 | 短句。不解释。 |
| 游戏内表现 | 琥珀色 `#f2b13c`，无台词，只有结算时一行 |

### P2 · 「回声」（ECHO-02）

| 项 | 内容 |
|---|---|
| 车体 | 试验场二号车，青色涂装，比一号轻 |
| 性格 | 话多，负责给沉默的那位翻译 |
| 台词基调 | 半句话 + 一个问句 |
| 游戏内表现 | 青色 `#58c8d8` |

**两个角色没有玩法差异**——数值完全一致。差异只在颜色和结算文案。这是有意的：双人是同屏协作，不该有人当副手。

## 舞台

五张地图共用同一套战场语言，但地形规则各不相同（详见 `docs/maps.md`）：

| 地图 | 一句话 |
|---|---|
| 试验场 | 基准图，只有砖墙和钢柱 |
| 丛林 | 草丛双向遮挡视线，能烧掉 |
| 冰原 | 冰面惯性滑行，冲刺是唯一急停 |
| 水网 | 深水只有渡水坦克能过，桥能被打塌 |
| 废墟 | 高墙挡炮线，残楼倒塌对双方都造成伤害 |

**这五张图是同一场战争的五个战场。** 战役线（`docs/campaign.md`）按战争发生的顺序
逐个回收：试验场是停机令事故的现场，冰原是夜袭，丛林是反攻停住的地方，
水网是撤退时被自己人炸掉的桥，废墟是打了 11 天的街区。

**每局重生成**，但规则固定：中心 205px 半径永远空着，砖墙 62 处，钢柱 15 处。所以你每次进来都认得这个场地，但记不住它的具体形状。

上面这张图是**试验场**。丛林、冰原、水网、废墟的地形各有自己的规则——草丛会挡住视线、冰面会滑、深水只有渡水坦克能过、残楼会塌。见 `docs/maps.md`。

## 结算文案

| 结果 | P1 视角 | P2 视角（双人） |
|---|---|---|
| 失败 | 「车还在。人没了。」 | 「我说过别冲那么前。」 |
| 胜利 | 「拖出来了。」 | 「看吧，我就说能行。」 |

**只有这两行。** 不做长篇叙事——8 分钟的街机游戏，玩家不会读。

## 不做

- 不做开场 CG、不做字幕、不做语音
- 不做角色解锁（两个角色一开始就都在）
- 不做剧情分支
- 不做图鉴
