# 技能卡 v2：稀有度 + 改装方向

> **状态：已实现（`src/data/cards.ts` + `src/game.ts`）。**
> v1（`docs/cards.md`）的"5 流派 × 4 级"已被本文取代；v1 第 0 节的终极卡红线、
> 第 1 节的"一局 12 张"推演继续有效。
>
> **实现时落地的细节**（与初稿的差异，以代码为准）：
>
> - 机制常数全部在 `src/config.ts` 的 `cards` 段（卡表只写"改哪一项"，不写裸数字）
> - 抽取：`rollOffers()` 保证"≥1 新装置 + ≥1 改装"，`pity` 计数在 `openLevelup()` 递增
> - 红卡：`time >= prototypeAfter(240s)` 且未拿满 2 张才进池
> - 超载核心：每发 +9 热、每秒 −12、满热停火 1.0s（实测占空比 ≈ 0.93 → 净增 ≈ +25%）
> - 磁吸雷：把 80px 内的敌人拉向雷；绊索额外减速 40%
> - 引力井对 BOSS 无效（不被拉），只吃伤害
> - 调试：控制台 `__tank`（Game 实例）与 `__tankCards`（卡表），`debugGive(tag, n)` 按类发卡
>
> **改这一版的原因**：v1 的"4 级逐级累加"在实战里长这样——
> `穿甲弹芯 → 硬化弹体 → 贯穿引信 → 长杆弹`，四张卡都是"穿透 +1"，
> 玩家抽到第 2 张时会觉得"这不是我刚拿过的那张吗"。同一流派内 Ⅱ 级是形态卡
> 这条规则救了火力，救不了穿透。**问题不在数值，在结构：把"同一件事的四次加强"
> 拆成了四张卡。**

## 0. 一句话

**稀有度决定"多久见一次、值不值得为它改打法"，改装方向决定"这张卡这一次变成什么"。**
等级不再是 `+1`，而是一次二选一的分叉。

## 1. v1 诊断：哪些卡没人会选

判定标准见第 2 节。结论先给：

| 卡 | 为什么没人选 | 判定 | 处置 |
|---|---|---|---|
| `pierce-2` 硬化弹体 | 唯一收益是"对砖墙 ×1.5"。砖墙密度由地图决定，玩家抽卡时看不到自己这张图有多少墙——**抽到就是赌** | 鸡肋 | 删，墙伤变成「穿甲弹」的一个方向 |
| `pierce-3` 贯穿引信 | 衰减 30% → 15%。这个数字**在屏幕上完全看不见**，玩家无法验证自己变强了 | 不可感 | 删，并入「穿甲弹」方向 |
| `blast-4` 燃烧残留 | 8dps × 3s = 24 点总伤害 = 参照 DPS 的 12%，还是**延迟到账**（敌人得站在火里） | 数值废 | 重做成独立卡「燃油弹」（可点燃、可拖火痕、可喷流） |
| `auto-2` 布雷器 | 唯一奖励"站着不动"的机制。本作最优策略是 8 分钟风筝，**它与核心循环相反** | 机制错 | 重做成「磁吸雷」：靠近就吸附追踪，跟着走 |
| `auto-4` 弹幕协调 | 纯 `+1 无人机`、`冷却 ÷1.25`。没有任何新行为 | 纯数值 | 删，这两个数变成「僚机」的改装方向 |
| `survive-2` 强化引擎 | 移速 +8.5%。**低于可感阈值**（见第 2 节 12%），玩家感觉不到 | 不可感 | 重做成「相位冲刺」：穿过敌人 + 残影爆炸 |
| `survive-3` 维修组 | 0.85/s 在 8 分钟里回 408 血，但呈现方式是"血条自己慢慢动"，与"受击→找补给"的节奏打架 | 无反馈 | 重做成「纳米修复」：脱战瞬回 + 击杀脉冲 |
| `fire-3` 稳压装填 | 和 `fire-1` 同一张卡（+6 伤害 / +11% 射速 vs +5 / +9%）。`cards.md` 自己承认"仍偏重复" | 重复 | 删，变成「主炮校准」的改装方向 |
| `survive-4` + `survive-x` | 4 级护盾和终极只差"多了冲击波"，中间那次升级等于白给 | 合并 | 合成一张「力场护盾」，冲击波是它的改装方向 |

**留在原地的**：`fire-1/2/4`（拆成主炮校准 + 双联炮两张）、`pierce-1`（升格为「穿甲弹」）、
`blast-1/2/3`（合成「高爆装药」+ 空爆/集中）、`auto-1/3/x`、`survive-1`、五张卡的结构
（并存进改装方向）。

### 1.1 相似性诊断：穿透族是病灶

四张卡的差别是：+1 穿透、+1 穿透 + 墙伤、+1 穿透 + 衰减、+2 穿透 + 暴击。
**玩家在卡面上看到的是同一个句子重复四次。** 更糟的是穿透在本作的收益前提是
"敌人排成一条线"，而敌人是从四周径向收拢的——只有正对某个刷怪方向时才成立。

改法不是"给穿透族加花色"，而是**把四次加强收成一张卡 + 三个互斥方向**：

```
穿甲弹（一张）
  ├─ A 贯穿：穿透 +2，衰减 0.85     ← 打纵列
  ├─ B 穿墙：穿墙 + 对砖墙 ×1.5，穿透 −1  ← 打地形
  └─ C 破甲：穿透 +1，无视护甲 40%   ← 打重甲
```

三选一之后，这张卡在三条不同的局里长得不一样，而卡池里只占一张。
**火力族同理**：主炮校准 A 射速 / B 单发，双联炮 A 四联 / B 收束。

## 2. 可感阈值（"鸡肋"的量化标准）

一张卡值得被选，必须满足**其一**；只加数值时，增量必须过阈值：

| 维度 | 可感阈值 | 反例 |
|---|---|---|
| DPS | ≥ 参照 DPS 的 **12%**（≈ +24） | 火池 8dps = 4% |
| 射速 / 冷却 | ≥ **12%**，且要改变"每波能开几次"的整数感 | `cd ÷1.25` 单独看等于没有 |
| 移速 | ≥ **12%** | +8.5% |
| 生命 | ≥ **20 点** | +18 勉强过关（血条可见） |
| 范围（半径） | ≥ **+25%**（面积 +56%）才看得出来 | +20 半径 / 34 底数 = +59% 面积，过关 |
| 穿透衰减、暴击率、墙伤 | **一律不算可感**，必须附带别的变化 | 0.7→0.85 |
| 触发类（护盾 / 连锁 / 冲击波） | 只要"每波至少能触发一次"就算可感，不看 DPS% | — |

**低于阈值的卡不是"弱卡"，是"界面上的空白"。** 玩家选完没感觉，下次就不会再选。

## 3. 稀有度：频率与角色，不是强度阶梯

### 3.1 为什么不能做成白 < 绿 < 蓝 < 金 < 红

如果稀有度等于强度，理性玩家会**跳过所有白卡等更好的**——12 次选择里有一半是空转。
所以稀有度的定义是：

| 稀有度 | 色 | 角色 | 玩家拿到时的预期 |
|---|---|---|---|
| **常规** | 白 `#d8dde6` | 补缺口。1 张就能感到 | "这下好打一点了" |
| **精制** | 绿 `#6fcf7a` | 给一条明确方向 | "我要走这条路" |
| **军用** | 蓝 `#4aa3ff` | 改变交战方式（距离/范围/时间） | "我打的方法变了" |
| **稀有** | 金 `#f2b13c` | 一条构筑的引擎 | "这局围绕它打" |
| **原型** | 红 `#ff4d4d` | 天生定义一局，**必须带代价** | "我要为它让路" |

**"天生红"是什么意思**：轨道炮、时停、超载核心改变的是**射击的时机**，不是射击的数值。
这种机制只要出现两张，整局就会变成"围绕它们转"，所以它们必须稀有——
不是因为它们数字更大，而是因为它们**重新定义你怎么玩**。

### 3.2 出现权重

| 稀有度 | 权重 | 12 次选择里的期望张数 | 说明 |
|---|---|---|---|
| 白 | 52 | ≈ 6.2 | 主力填充 |
| 绿 | 26 | ≈ 3.1 | 构筑骨架 |
| 蓝 | 14 | ≈ 1.7 | 打法切换 |
| 金 | 6 | ≈ 0.7 | 引擎 |
| 红 | 2 | ≈ 0.25 | 一局 0–1 张 |

**保底**：连续 **6 次**升级没出现过金或红 → 第 7 次必出 1 张金/红。
**限制**：红卡第 4 分钟前不出；一局最多 **2 张**红（保证红线 ② 不被叠加突破）。

## 4. 改装：每次升级是一次分叉，不是 +1

### 4.1 规则

| 项 | 规则 |
|---|---|
| 卡的最高状态 | 基础 + **1 次改装**（每张卡只有一次分叉，选完即定） |
| 方向数量 | 白卡 2 个，绿/蓝/金/红 3 个；每次只从其中**随机展示 2 个** |
| 互斥 | 选了 A，B/C 永久消失。同一张卡在两局里可以完全不同 |
| 代价 | 改装方向**允许带代价**（射程换伤害、范围换 DPS）——这是构筑的乐趣 |
| 视觉 | 每个方向必须改变画面上的某样东西（半径、炮口颜色、落雷密度） |

**为什么只给一次分叉**：分叉两次会变成"升星"（同一张卡吃三份资源），
而现在的重点是**组合**（燃油弹 + 引力井），不是把一张卡堆满。
一局 12 次选择里大约 **8 次拿新装置 + 4 次改装**，正好卡在
"要么摊开、要么收窄"的平衡点上。

### 4.2 分叉不是"更好"，是"不同"

- 燃油弹 A 广域焦土：半径 +60%，DPS −25% → 更广更慢，配引力井
- 燃油弹 C 高压喷流：改成短距直喷，无飞行延迟，冷却 −30% → 更近更快，配冲刺
- 两条路的 DPS 期望接近，**差别在"你能站在哪打"**

## 5. 三条轴：距离 / 范围 / 时间

v1 所有攻击都在 250px 中距离，等于没有距离这一维。v2 每张攻击卡必须在表里声明主轴，
且**卡池要覆盖到三轴的每一格**，否则"选卡"退化成"选数字"。

| 轴 | 取值 | 怎么改变玩法 |
|---|---|---|
| 距离 | 近 0–140 / 中 140–360 / 远 360–700 | 决定你站在哪：贴脸、拉扯、还是隔着墙打 |
| 范围 | 点 / 线 / 扇形 / 圆 / 跳 / 区域 | 决定你怕不怕被围 |
| 时间 | 瞬时 / 延迟 / 持续 / 周期 | 决定你是"反应"还是"预铺" |

**覆盖检查**（第 6 节卡池统计）：近距 3 · 中距 9 · 远距 3 · 无距离（自主/生存）14；
点 9 · 线 3 · 扇形 2 · 圆 6 · 跳 5 · 区域 4；
瞬时 16 · 延迟 3 · 持续 7 · 周期 3。近距偏少是刻意的——近距靠坦克签名与冲刺补，
如果后续加卡，优先补近距。

> 每张红卡**必须写清代价**，且过第 0 节三条红线（收益由操作触发 / 增量 ≤ 35% / 有场景上限）。

## 7. 抽取规则

| 规则 | 内容 |
|---|---|
| 每次升级 | 出 **3 张**，互不重复 |
| 构成 | 至少 1 张**新装置** + 至少 1 张**改装**（两类都可用时）；前两次升级强制 2 新 + 1 改装 |
| 权重 | 新装置按第 3.2 节稀有度权重；**改装不按稀有度**（池子小，按等权） |
| 同类加成 | 同类已有 ≥2 张时，该类新装置权重 ×1.2（替代 v1 的 ×1.35） |
| 改装选项 | 该卡 3 个方向里随机展示 2 个（白卡 2 个全展示） |
| 排除 | 已拥有的装置不再作为"新装置"出现；已改装的卡不再作为"改装"出现 |
| 保底 | 连续 6 次无金/红 → 下一次必出；红卡第 4 分钟后才可能出，一局上限 2 张 |
| 兜底 | 新装置与改装都不可用 → 「补给卡」（回 25 血 + 1 炸弹） |
| 重选 | 每局 2 次（`west` / `KeyQ`），重选不消耗保底计数 |
| 多样性 | 3 张里至少 **2 个不同类**（直射/面域/场控/自主/生存/经济） |

## 8. 卡面（UI）

稀有度是**看得见**的，否则它只是内部权重：

| 元素 | 做法 |
|---|---|
| 边框 | 白 = 细灰描边，绿/蓝/金 = 对应色描边 + 内侧微光，红 = 描边 + 呼吸脉冲 |
| 色条 | 卡面顶部 3px 稀有度色条（色盲也能靠长度/亮度区分） |
| 轴标签 | 左下角小字：`近` / `中` / `远` / `自主`，让"站哪打"一眼可见 |
| 改装方向 | 卡面下方并排两块，各带一个图标，显示**变化的量**（如 `半径 +60% / DPS −25%`） |
| 已拥有的卡 | 卡面右上角显示已选方向的小徽标，避免"我拿过这张吗" |

**红色卡面必须与金/蓝明显不同**：它是这一局的高光时刻，值得一次专属动效（扫描线划过 + 边框过载闪烁）。

## 9. 红线复核（红卡）

| 红卡 | 参照增量（估） | 触发方式 | 场景上限 | 判定 |
|---|---|---|---|---|
| 轨道炮 | ≈ 33%（v1 实测） | 玩家主动蓄力站定 | 一线 4 目标封顶 | ✅ |
| 超载核心 | +35% 上限 × 可用率 ≈ 28% | 玩家自己控热量 | 热量满停火，密集时被迫停 | ⏳ 待实测 |
| 时停核心 | 伤害增量 <10% | 玩家主动静止 | 45s 一次，只解围不输出 | ⏳ 待实测 |

**引力井 + 燃油弹**这类组合是 v2 最大的不确定项：聚怪本身不加伤害，但会把燃油的
有效覆盖从"命中 3 个"变成"命中 8 个"。**必须实测**，必要时给引力井加"被拉住的敌人受到
范围伤害 −20%"的隐藏系数。

## 11. 不做的事（更新）

| 不做 | 为什么 |
|---|---|
| 稀有度 = 强度阶梯 | 玩家会跳过白卡等红卡，12 次选择一半空转 |
| 同一张卡分叉 2 次以上 | 变成升星，与"组合"冲突 |
| 词条随机（伤害 +5~15%） | 与"选择"冲突，见 v1 第 11 节 |
| 负作用卡（伤害 +50%，移速 −20%） | 仍然是：取舍由"放弃别的卡"承担。**但改装的代价可以存在**——代价必须写在卡面上，且不超出该卡的收益 |
| 卡池超过 32 张 | 一局只摸到 8 张装置，再多是装饰 |
| 红色卡超过 3 张 | 再多就不是"高光"，是"标配" |
